## 🎮 Interactive Learning Experience

Every learning module ends with a comprehensive practice quiz. You can read these directly in Markdown or play them using our built-in **Interactive Quiz Player**.

### 🕹️ How to play the Quizzes:

1.  **Navigate to the Player**: Open a terminal in the `markdown_quiz_app` directory.
2.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```
3.  **Launch the Server**:
    ```bash
    python main.py
    ```
4.  **Open in Browser**: Navigate to `http://127.0.0.1:8000`.
5.  **Load a Quiz**: Drag-and-drop any `.md` quiz file from the `guides/` folder into the browser window to start your interactive assessment!

## 🧠 Educational Philosophy

Our content follows a **Multi-Stage Mastery** approach:

1.  **The Executive Summary**: High-level context and "Why this matters."
2.  **Core Pillars**: Technical deep-dives into fundamental mechanics.
3.  **Logic Walkthroughs**: Real-world code examples and sequence diagrams.
4.  **Active Recall**: Practice quizzes with **Hints** and **Detailed Rationales** to turn mistakes into learning moments.

> [!TIP]
> **Always read the Rationale!** Even if you get a question right, our rationales explain *why* the other options were sub-optimal, giving you a deeper architectural understanding.
